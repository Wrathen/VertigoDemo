# Vertigo Games Demo

- <b>Unity Version:</b> 2021.3.45f2 LTS

- Once opened, navigate to Scenes/Game.scene

- To change wheel slots, use the scriptable objects at Data/ folder.

- The demo is using Weighted Random to decide on the outcome of the wheel spin. Weights can be altered through the scriptable objects in the Data/ folder. The outcome is decided the moment you click the Spin button, not after the animation.

- Compatible with 16:9, 20:9, 4:3 aspect ratios.
